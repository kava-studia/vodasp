# VodaSP

Личный диспетчер доставки воды по Сергиеву Посаду.

## Запуск

Статическое приложение из public/, деплой на Vercel. Личные маршруты хранятся в AES-256-GCM. Ключ передаётся во фрагменте личной ссылки, на сервер не отправляется. Открывать маршрут можно по личной ссылке или импортировать JSON.

Данные, правки и ключ сохраняются в браузере устройства. Они не синхронизируются между телефонами. Для переноса выгрузите JSON.

## Планирование

Порядок сгруппирован по районам с учётом окон доставки. Время переездов задаётся пользователем, не является расчётом по дорожной сети и не учитывает пробки. Нет заявлений об оптимальности расстояния. Число бутылей в исходном фото не распознано. Неуверенные строки помечены для сверки.

Касса клиентов отделена от заработка водителя. Расходы считаются по введённым пробегу, расходу и цене топлива. Неизвестные значения не заменяются нулевым прогнозом.

## Безопасность

Не добавляйте исходные маршрутные листы, телефоны, открытые JSON или ключи в публичный репозиторий. Ссылку с ключом передавайте только исполнителю доставки. Внешние ссылки используют noreferrer. Нет аналитики, внешних шрифтов или внешнего API геокодирования.
